# ㈜엠케이전기물류 홈페이지

정적 홈페이지 파일입니다. 빌드 과정 없이 그대로 올리면 됩니다.

## 구성
- `index.html` — 메인 (원페이지)
- `privacy.html` — 개인정보처리방침
- `assets/` — 로고, 매장·창고 사진
- `assets/brands/` — 취급 브랜드 로고 12개
- `robots.txt` — 검색엔진 안내

## 채워야 할 곳
화면에 노란 칸(`class="ph"`)으로 표시된 부분이 미정 정보입니다.
`index.html`과 `privacy.html`에서 `class="ph"`로 검색하면 전부 찾을 수 있습니다.

## 견적 폼 연결
`index.html`의 `https://formspree.io/f/YOUR_FORM_ID`를 폼 서비스에서 받은 주소로 바꾸세요.
바꾸기 전까지는 폼을 제출해도 메일이 오지 않습니다.

## 링크 연결
- 기업전용 B2B몰 버튼은 지금 페이지 안의 B2B 안내(`#b2b`)로 이동합니다. B2B몰 주소가 정해지면 바꾸세요.
- 네이버 지도 버튼은 각 매장의 네이버 지도 공유 링크로 바꾸세요.

## 사진 교체
`assets/` 안의 같은 이름 파일을 고해상도 원본으로 덮어쓰면 됩니다.

## 브랜드 로고
회사소개서 협력업체 페이지에서 가져온 이미지입니다. 공개 전 각 브랜드의 로고 사용 가능 여부를 확인하세요.
